SASS (Syntactically Awesome Style Sheets)

CSS preprocessor that adds advanced features like variables, nesting, and mixins.

Contains two different syntaxes:

  • SCSS (.scss) - Similar to CSS using {} and ;
  • Sass (.sass) - Indented without {} and ;

Below are some examples of the benefits of using the tool, in both syntaxes. The file name in the first line of each example shows which one it is.

Variables

#
// styles.scss
$primary-color: #007bff;
$spacing: 1rem;

.btn {
  background: $primary-color;
  padding: $spacing;
}

// styles.sass
$primary-color: #007bff
$spacing: 1rem

.btn
  background: $primary-color
  padding: $spacing

Nesting

#
// styles.scss
.nav {
  background: #333;

  &__list {
    display: flex;

    &__item {
      margin: 0 1rem;

      &:hover {
        color: $primary-color;
      }
    }
  }
}

// styles.sass
.nav
  background: #333

  &__list
    display: flex

    &__item
      margin: 0 1rem

      &:hover
        color: $primary-color

Mixins (Reusable functions)

#
// styles.scss
@mixin flex($position) {
  display: flex;
  justify-content: $position;
  align-items: $position;
}

.container {
  @include flex(center);
  height: 100vh;
}

// styles.sass
@mixin flex($position)
  display: flex
  justify-content: $position
  align-items: $position

.container
  @include flex(center)
  height: 100vh

The indented syntax also has a shorthand: =flex($position) declares the mixin and +flex(center) includes it.

Extensions (Placeholders)

#
// styles.scss
%button-base {
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
}

.btn-primary {
  @extend %button-base;
  background: blue;
}

.btn-secondary {
  @extend %button-base;
  background: gray;
}

// styles.sass
%button-base
  padding: 10px 20px
  border: none
  border-radius: 4px

.btn-primary
  @extend %button-base
  background: blue

.btn-secondary
  @extend %button-base
  background: gray

Partials and modules

#

Files whose names start with _ are partials: they aren't compiled on their own, only loaded by other files. @use loads a partial as a module, whose members are reached through a namespace (by default the file name), so names from different files don't clash. It replaces @import, which is deprecated and will be removed in Dart Sass 3.0.

// _variables.scss
$colors: (
  primary: #007bff,
  secondary: #6c757d
);

// main.scss
@use 'sass:map';
@use 'variables';

.btn {
  background: map.get(variables.$colors, primary);
}

// _variables.sass
$colors: (primary: #007bff, secondary: #6c757d)

// main.sass
@use 'sass:map'
@use 'variables'

.btn
  background: map.get(variables.$colors, primary)

@use 'variables' as * drops the namespace, and @use 'variables' as vars changes it.

Functions and Operations

#

Division with / is deprecated, since / is also a separator in CSS (as in grid-area: 1 / 3). Use math.div from the built-in sass:math module instead.

// styles.scss
@use 'sass:math';

@function calculate-rem($size) {
  @return math.div($size, 16px) * 1rem;
}

.container {
  font-size: calculate-rem(18px);
  width: math.div(100%, 3);
}

// styles.sass
@use 'sass:math'

@function calculate-rem($size)
  @return math.div($size, 16px) * 1rem

.container
  font-size: calculate-rem(18px)
  width: math.div(100%, 3)
